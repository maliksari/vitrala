# Vitrala

Support pages and privacy policy for **Vitrala**, a colouring book for iPhone
and iPad.

* Privacy Policy — https://maliksari.github.io/vitrala/privacy/
* Support — https://maliksari.github.io/vitrala/support/

This repository holds the published site only; the app itself is closed source.

[Issues](https://github.com/maliksari/vitrala/issues).
